# HamChat 2.7.0

HamChat 2.7.0 is a substantial release focused on memory, model awareness, reliability, and easier future updates.

## HamMem: persistent memory

HamChat can now preserve useful information beyond the immediate conversation.

* Create, edit, delete, and review memories in the new Memory Manager.
* Scope memories to a user, conversation, AI Profile, administrator, or the whole installation.
* Enable or disable HamMem independently for each conversation.
* Retain the conversation’s HamMem preference when forking a chat.
* Rebuild memory embeddings when required.
* Import previously exported chats through the HamChat interface.

Memory availability remains controlled by the signed-in user’s role and permissions.

## Thinking support

Compatible Ollama models can now expose their transient thinking process in a dedicated, collapsible Thinking panel.

* Select an available thinking-effort level.
* See thinking separately from the model’s final response.
* Models that do not support thinking keep the controls disabled.
* Models that require thinking are handled appropriately.

Thinking output is temporary diagnostic information and is not stored as ordinary conversation content.

## Smarter model and context handling

HamChat now understands the active Ollama model’s real runtime context more accurately.

* The Model Manager offers Auto, Low/4K, Mid/8K, and High/16K context-allocation choices.
* Request planning accounts for the full prompt and reserves space for the response.
* Oversized requests are stopped before they can fail unpredictably.
* HamChat provides useful guidance when a conversation no longer fits the selected context.
* Thinking capabilities are learned for each model build rather than guessed solely from its name.
* Additional diagnostics make interrupted or malformed model responses easier to identify.

## Improved image handling

Image attachments are validated and normalized before being sent to compatible models.

HamChat accepts WebP and other common raster formats supported by Pillow, creates a bounded PNG for model input, and preserves the original attachment bytes in its content-addressed storage.

## Safer paths and user data handling

Database, media, avatar, and attachment operations now consistently use HamChat’s selected data directory instead of relying on the directory from which the application happened to be launched.

The bundled default theme is treated as a read-only application resource and is no longer repaired or rewritten during normal use.

Optional user registry layers are also supported, allowing local context and modality customizations to remain separate from HamChat’s shipped defaults.

## Automatic updates

HamChat now contains its own secure update system.

The Updates menu provides:

* **Off**
* **Ask Before Installing**
* **Install Automatically**
* **Check for Updates**

Update checks run after the splash screen appears and before normal database and model initialization. A failed check does not prevent HamChat from starting.

Before an update is installed, HamChat verifies its release metadata, archive size, cryptographic digest, directory structure, and complete managed-file inventory. Installation is journaled and supports rollback and interrupted-update recovery.

The updater manages declared HamChat system files only. It does not install into `data/` or `settings/`, and it does not replace the database or content-addressed storage.

Updates requiring an incompatible database schema, data layout, or data migration are blocked from automatic installation.

## Database compatibility

When HamChat 2.7.0 starts for the first time, its normal startup process applies the required database schema migrations for persistent memory, embeddings, thinking support, and HamMem preferences.

This normal database upgrade is separate from the automatic updater. Existing conversations and user data remain in HamChat’s selected data directory.

## One final manual update

Installations older than 2.7.0 do not yet contain the new updater, so they must be upgraded to this release manually one final time.

After 2.7.0 is installed, compatible future releases can be discovered and installed through HamChat itself.
