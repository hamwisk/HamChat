# HamChat 2.7.1

HamChat 2.7.1 is a maintenance release correcting archive validation in the new automatic updater.

## Fixed

* Safe files outside the updater’s managed-file inventory no longer cause an otherwise valid tagged release archive to be rejected.
* HamChat continues to extract and install only files explicitly declared by the trusted update manifest.
* User-owned `settings/` and `data/` paths remain excluded from staging and installation.
* Existing protections against unsafe paths, symlinks, special archive members, collisions, archive-size abuse, and digest mismatches remain in place.

## Upgrade note

HamChat 2.7.1 supersedes 2.7.0 as the recommended initial updater-enabled release.

Because 2.7.0 contains the overly strict archive scanner, an existing 2.7.0 installation may require a manual update to 2.7.1. Compatible releases after 2.7.1 can then use HamChat’s automatic update path normally.
