# HamChat 2.7.3

## Easier image attachments

HamChat now has a visible attachment button beside the message box. You no longer need to drag and drop an image—or type its full file path—to include it in a conversation.

* Click the paperclip button to choose one or more images.
* Select multiple images together from the file chooser.
* Drag and drop either a single image or several images at once.
* Review or remove staged images before sending your message.
* Use the attachment control with a mouse, keyboard, touchpad or touchscreen.

The new attachment control is designed to fit naturally into HamChat’s uncluttered interface and works with both light and dark themes.

Existing image validation, thumbnail previews, vision-model support and local attachment storage continue to work as before.

## Clearer, better-formatted replies

AI replies can now display Markdown formatting instead of showing the formatting symbols as ordinary text. Longer and more structured answers are considerably easier to read.

HamChat now presents:

* headings and horizontal dividers;
* bold and italic text;
* ordered, unordered and nested lists;
* blockquotes;
* links;
* tables;
* inline code and multi-line code blocks.

Code blocks are displayed separately in a clean monospace font and wrap safely inside the message bubble. They remain readable when HamChat is resized, when the side panels are open and even at the application’s minimum window width—without introducing horizontal scrolling or allowing text to escape its bubble.

Normal replies continue to use HamChat’s clean sans-serif interface font. Messages remain plain while they are being generated and switch to formatted Markdown only after a response completes successfully, avoiding distracting layout changes during streaming.

Copying a message still gives you its original Markdown text. HTML and image-like markup inside code blocks is displayed literally rather than being treated as active content.

## Access to older conversations

The chat list initially shows your 50 most recent conversations while keeping older chats available.

Use **Load older chats** beneath the chat list to reveal earlier conversations in manageable batches. This keeps the side panel responsive without preventing access to longer chat histories. This button will only be visible when required.

## Smoother keyboard navigation

HamChat now places the typing cursor in the message box after you start a new chat or open an existing conversation. You can begin typing immediately without first clicking the message box.

Focus also returns to the message box when you close the top panel. Closing the side panel does the same when the top panel is not open. When you are working in an open top-panel form, closing the side panel leaves your cursor where it is.

## Logout confirmation

HamChat now asks for confirmation before logging you out, helping prevent accidental clicks from interrupting your session.

Choose **Log out** to continue, or **Cancel**, press Escape or close the confirmation window to remain logged in.

## Better Ollama model and memory management

HamChat now provides greater control over the models occupying your computer’s RAM and graphics memory.

* The Model Manager shows models suitable for conversation while hiding embedding-only models such as `nomic-embed-text` from the chat-model list. Embedding models remain available to HamMem.
* A new **Unload all models** button immediately releases memory used by currently loaded Ollama models.
* HamChat prevents unloading while a reply is being generated, avoiding interrupted responses.
* Closing HamChat now unloads its current Ollama chat model instead of leaving it in memory until Ollama’s automatic timeout expires.

Unloading a model does not delete it, change your selected model or affect your conversations. Ollama automatically loads the required model again the next time it is used. This makes it easier to free RAM and graphics memory before opening demanding applications such as image or video generators.

## Easier version information

A new **Help → About HamChat** dialog shows the installed HamChat version and database schema version. The update checker also reports your installed version when HamChat is already up to date.
