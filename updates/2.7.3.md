# HamChat 2.7.3

## Easier image attachments

HamChat now has a visible attachment button beside the message box. You no longer need to drag and drop an image—or type its full file path—to include it in a conversation.

* Click the paperclip button to choose one or more images.
* Select multiple images together from the file chooser.
* Drag and drop either a single image or several images at once.
* Review or remove staged images before sending your message.
* Use the attachment control with a mouse, keyboard, touchpad or touchscreen.

The new attachment control is designed to fit naturally into HamChat’s uncluttered interface and works with both light and dark themes.

Existing image validation, thumbnail previews, vision-model support and local attachment storage continue to work as before.

## Clearer, better-formatted replies

AI replies can now display Markdown formatting instead of showing the formatting symbols as ordinary text. Longer and more structured answers are considerably easier to read.

HamChat now presents:

* headings and horizontal dividers;
* bold and italic text;
* ordered, unordered and nested lists;
* blockquotes;
* links;
* tables;
* inline code and multi-line code blocks.

Code blocks are displayed separately in a clean monospace font and wrap safely inside the message bubble. They remain readable when HamChat is resized, when the side panels are open and even at the application’s minimum window width—without introducing horizontal scrolling or allowing text to escape its bubble.

Normal replies continue to use HamChat’s clean sans-serif interface font. Messages remain plain while they are being generated and switch to formatted Markdown only after a response completes successfully, avoiding distracting layout changes during streaming.

Copying a message still gives you its original Markdown text. HTML and image-like markup inside code blocks is displayed literally rather than being treated as active content.
